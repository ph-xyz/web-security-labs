# Client-Side Auth Lab

A local lab I used to practice client-side authentication testing.

**Requirements:** Node.js and a browser with DevTools.

**Run:**
```bash
node server.js
```

Open `http://127.0.0.1:31338`.

**Objective:** access protected application data without a valid external identity.

**Skills practiced:**
- Frontend JavaScript analysis
- Client-side authentication testing
- Backend token-validation review

> Intentionally vulnerable. Use only locally or in authorized environments.
