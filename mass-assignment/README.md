# Mass Assignment Lab

A local lab I used to practice mass assignment in an account update flow.

**Requirements:** Python 3 and a browser or HTTP proxy.

**Run:**
```bash
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.

**Credentials:** `demo@local.test:password123`.

**Objective:** identify sensitive fields accepted by the profile update API.

**Skills practiced:**
- API request manipulation
- Mass assignment and overposting testing
- Server-side field validation review

> Intentionally vulnerable. Use only locally or in authorized environments.
